# Pumpkin Marketplace - Issue Tracker

This is the public issue tracker for [Pumpkin Marketplace](https://pumpkinmc.org). The source code is maintained in a private repository.

## How to Contribute

- **Bug Reports**: Found something broken? [Open a bug report](https://github.com/Purdze/pumpkin-marketplace-issues/issues/new?template=bug_report.yml)
- **Feature Requests**: Have an idea? [Request a feature](https://github.com/Purdze/pumpkin-marketplace-issues/issues/new?template=feature_request.yml)

## Guidelines

- Search existing issues before creating a new one to avoid duplicates
- Provide as much detail as possible (steps to reproduce, screenshots, browser info)
- Be respectful and constructive
